NEON ARENA .IO - VERSION GRATUITE PRÊTE À DÉPLOYER

1. En local
- Installe Node.js 18+
- Ouvre un terminal dans le dossier
- Lance: npm install
- Lance: npm start
- Ouvre: http://localhost:3000

2. Publier gratuitement sur Render
- Crée un compte GitHub gratuit
- Crée un nouveau repository
- Envoie tous les fichiers de ce dossier sur GitHub
- Va sur Render
- New + > Web Service
- Connecte ton repository GitHub
- Render détectera render.yaml
- Clique Deploy
- À la fin, partage l'URL publique onrender.com

3. Important
- Le plan gratuit peut se mettre en veille quand personne ne joue.
- Dès que quelqu'un rouvre le lien, le service redémarre.

4. Ce que tu peux ajouter ensuite

- dash
- compétences
- projectiles spéciaux
- mobs et boss
